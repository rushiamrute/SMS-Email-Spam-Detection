# 📩 SMS Spam Detection

This project uses Natural Language Processing (NLP) and Machine Learning to detect whether an SMS message is **spam** or **not spam**. It includes data preprocessing, exploratory data analysis (EDA), model training, and evaluation.

---

## 🚀 Features

- Data cleaning and preprocessing
- Visualizations (word clouds, bar plots, heatmaps)
- Feature extraction using TF-IDF
- Model training using Naive Bayes
- Real-time prediction on custom messages
- Evaluation with accuracy, confusion matrix, and more

---

## 🧠 Algorithms Used

- Multinomial Naive Bayes
- CountVectorizer / TfidfVectorizer
- NLTK for NLP preprocessing

---
## 📊 Model Accuracy
- Accuracy: 97%
- Precision: 100%
- Recall: 95%
---
## 🤖 Libraries Used
- pandas
- matplotlib, seaborn
- nltk
- scikit-learn
